What changed?

V7 uses QAQᵀ. The new arms use UVᵀ/N: one Gaussian group versus three randomly sampled groups. No group has an assigned dynamical role.

The two new arms have the same overall factor means, covariances, structured eigenvalues and singular values. The three-group arm changes their higher-order pattern distribution. Feedback strength matches V7; individual connection patterns and their alignment with the fixed input and random background change.

Each group has sampled means and covariances; a common analytic centering/whitening step matches the overall moments. This is a sampled engineering prior, not a fitted cortical model. No new biases, time constants, rank changes or designed oscillators.

Native trajectories have a 3 s warmup; input-off trajectories start from the same specified initial vector in every arm. Metrics use 16–24 s, across all variables. Dimension is the covariance participation ratio; it does not measure computation. A finite trajectory does not establish an asymptotic regime, chaos, realism or pretraining value.
